# Why Are We Here?

## Working position

I am not learning programming to compete with AI at producing code. I am learning it so that I can understand, question, and direct computational systems without losing my creative intention in translation.

## Questions for the first draft

- Which moment from my own creative practice best shows the difference between code that runs and a system that does what I intended?
- What must I understand before I can judge code proposed by an AI assistant?
- How could programming knowledge change the way I work as a multidisciplinary designer and future producer?
- Which parts of programming may become obsolete, and which forms of judgement will remain valuable?

## Material to develop

- One concrete incident from a project, described in detail
- Notes and a response to *The Art of Code*
- A counterargument that takes AI-generated code seriously
- Verified sources and an APA-formatted bibliography
