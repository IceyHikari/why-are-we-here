# From Generated Assets to a Playable System

## Working thesis

I am not learning programming to compete with AI at producing code. I am learning it to understand how creative intentions become rules, data, and behaviour. During my AIGC-assisted game project, I found that a model could generate images, animations, or fragments of code, but it could not automatically turn them into one coherent and playable system. Programming gives me the judgement needed to direct that process without surrendering creative control.

- Acknowledge the speed, variation, and exploratory value of generative AI.
